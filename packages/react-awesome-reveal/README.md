# react-awesome-reveal

Version 5 of `react-awesome-reveal` re-exports `@awesome-reveal/react`. It gives `Reveal`, `useReveal` and their types, and it loads its stylesheet automatically.

```tsx
import { Reveal } from "react-awesome-reveal";

<Reveal from="left">Hello</Reveal>;
```

For the API and the migration from version 4, read the [React documentation](https://www.npmjs.com/package/@awesome-reveal/react). The license is MIT.
