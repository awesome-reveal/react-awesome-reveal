React Awesome Reveal is now [`@awesome-reveal/react`](https://www.npmjs.com/package/@awesome-reveal/react). Version 5 of this package re-exports it, with the same entry points:

| Import path                      | Same as                           |
| -------------------------------- | --------------------------------- |
| `react-awesome-reveal`           | `@awesome-reveal/react`           |
| `react-awesome-reveal/keyframes` | `@awesome-reveal/react/keyframes` |

Install `@awesome-reveal/react` in new projects:

```sh
pnpm add @awesome-reveal/react
```

## Migrating from v4

Version 5 is not compatible with v4. It has no effect components, such as `Fade` or `Slide`, and it does not use Emotion. Read [Migrating from v4](https://www.npmjs.com/package/@awesome-reveal/react#migrating-from-v4).

This package includes the `migrating-from-v4` agent skill, which helps a coding agent do the migration.

The v4 documentation is in the [README of `react-awesome-reveal@4.3.1`](https://github.com/awesome-reveal/awesome-reveal/blob/react-awesome-reveal%404.3.1/README.md).
